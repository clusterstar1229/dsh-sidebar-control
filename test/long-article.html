Latency notes

Batch latency is the wall-clock time from the first step to the last step inside one call. Batch latency grows with the number of steps that wait for navigation, and it stays flat for pure DOM steps.

When a batch mixes typing, submission and a query read, batch latency is dominated by the page load rather than by the executor; on a local fixture the same batch finishes in roughly two hundred milliseconds.
